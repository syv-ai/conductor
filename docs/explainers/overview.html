    Conductor

    Conductor is a Python library that runs graphs of typed nodes. You write Python functions. Someone else wires them together in an editor, and the graph reaches you as JSON. Conductor checks that graph, tells you what's wrong with it, and runs it.

    It needs only pydantic, polars and typing-extensions. It has no web framework, database or login, and it uses none of a host's words. Those belong to the application that uses it, which conductor calls the host.

    A node is a typed function.

    Its parameters are its inputs and its return type is its outputs. Nothing is declared twice.

    @node("shout", title="Shout", description="…")
def shout(line: str) -> str:
    return line.upper()

    A graph is a JSON record.

    An editor saves it, and code writes the same record with make_graph. You compile it against a registry.

    {
  "inputs": {
    "line": {}
  },
  "nodes": {
    "shout": {
      "node": "shout",
      "inputs": {
        "line": {
          "graph_input": "line"
        }
      }
    }
  },
  "outputs": {
    "result": {
      "node": "shout",
      "output": "result"
    }
  }
}

    A run is JSON you save and resume.

    It can wait days for a person, then go on in another process. A call that's finished in the saved run isn't made again.

    saved = run.to_json()
# days later, anywhere
run = Run.from_json(saved, graph)
run = run.with_answers(run.waiting[0], True).resume()

    The design choices

    Each one points to the page that shows it. The rules are in the reference, python -m conductor.about.

    A node is a typed function, and its signature is its interface.Public

    A node and its types shows one.

    A graph is data, and there's no @graph.Public

    The graph record and compiling shows the record.

    Compiling reports problems instead of raising.Public

    Problems shows what a problem holds.

    The types decide one or many.Public

    Series and tables shows a loop.

    Behaviour is a value, not a flag.Public

    Asking a person shows Ask, and A node and its types SKIPPED.

    A value from outside is checked once, where it comes in.

    Problems shows a refused value at its door.

    One scheduler runs a run, with or without a listener.

    Running and streaming shows resume() and stream().
